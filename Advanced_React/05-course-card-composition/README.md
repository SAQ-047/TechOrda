# 05. Карточка через композицию

[Папка решения на GitHub](https://github.com/SAQ-047/TechOrda/tree/main/Advanced_React/05-course-card-composition).

Один компонент `Panel` используется для фильтра и всех карточек курсов. Данные импортируются из локального `src/courses.json`. Пример использует общие зависимости курса; предыдущие задания сохранены отдельно.

## Запуск

Из `Advanced_React`:

```bash
npm ci
npm run dev:05
```

Адрес: `http://127.0.0.1:5177/`. После общей установки внутри `05-course-card-composition` также работает `npm run dev`.

Production:

```bash
npm run build --workspace=05-course-card-composition
npm run preview:05
```

Preview: `http://127.0.0.1:4177/`. `npm run build` из `Advanced_React` собирает все задания. Пакеты и lockfile общие: `Advanced_React/node_modules` и `Advanced_React/package-lock.json`.

## Композиция

`Panel({ title, children, actions })` задаёт общую структуру: секция, заголовок, необязательная область действий и содержимое. `useId` связывает заголовок с `aria-labelledby`, поэтому каждая панель имеет доступное имя.

Внутри `Panel` нет данных курса, сравнений его id, фильтрации, обработчиков выбора или флагов `isCourse / isFilter / showButton`. Условие проверяет только наличие `actions`. Заголовок приходит через `title`, содержимое — через `children`, готовые элементы управления — через `actions`.

`App` использует этот же компонент двумя способами:

- Фильтр: длинный заголовок и подписанный select в `children`; `actions` не передаётся.
- Карточки: название курса в `title`, сведения о категории, местах и версии в `children`; обычная кнопка «Выбрать» передаётся через `actions`.

Фильтрация и выбранный id находятся в `App`. Кнопка показывает выбранный курс в статусе страницы. Выбор доступен для всех четырёх курсов, в том числе с нулём мест: бронирование и ограничения доступности не входят в это задание. Записи в localStorage нет.

## Пустой actions, длинный заголовок и клавиатура

При отсутствии `actions` компонент не создаёт его контейнер или кнопку-заглушку. Заголовок и обёртки не получают `tabIndex`; в фильтре остаётся только настоящий select.

Заголовок переносится благодаря `overflow-wrap: anywhere` и `min-width: 0`. Шапка использует flex с переносом строк: если места мало, область действий переходит ниже заголовка. Содержимое остаётся отдельным блоком после шапки; обрезания текста нет.

Действия переданы как нативные `<button type="button">`. Они получают фокус по Tab и активируются Enter или Space. Для select и кнопок задан видимый `:focus-visible`; у Panel нет искусственной клавиатурной обработки или дополнительных интерактивных элементов.

## Версии и самопроверка

React / React DOM 19.3.1, Vite 8.3.6, @vitejs/plugin-react 6.3.0. Проверка на Node.js 20.20.2 и npm 10.9.4. Версии и дерево зависимостей закреплены в общих [package.json](../package.json) и [package-lock.json](../package-lock.json).

Проверено 9 ноября 2026 года: `npm ci` и сборка всех пяти workspaces прошли. Сценарии в Brave проверены через Playwright Core.

| Проверка | Dev + StrictMode | Production |
| --- | --- | --- |
| Фильтр и четыре карточки используют общий Panel, секции имеют доступные имена и уникальные id заголовков | PASS | PASS |
| У фильтра без actions нет контейнера действий и кнопки-заглушки | PASS | PASS |
| Порядок Tab: select → четыре кнопки; Shift+Tab возвращает на предыдущую кнопку | Пять остановок, без лишних элементов | То же |
| Выбор через Enter и Space | Все четыре курса выбраны с клавиатуры, фокус виден | То же |
| Фильтр категорий | Frontend — 2, Fullstack — 1, Quality — 1, все — 4 | То же |
| Ширина 1280 / 360 / 320 px | Длинный заголовок фильтра занимает 2 / 4 / 6 строк; горизонтальной прокрутки нет | То же |
| Длинный заголовок без пробелов рядом с actions | Заголовок, кнопка и содержимое не перекрываются | То же |
| Ошибки JavaScript и загрузки ресурсов | 0 | 0 |

В проверке длинного непрерывного текста заголовок одной карточки временно заменялся в DOM: это проверка CSS-вёрстки, данные приложения не менялись. Во всех размерах заголовок и actions остались внутри панели, а тело — ниже шапки.

Для ручной проверки:

1. Нажимайте Tab: сначала фокусируется категория, затем кнопки четырёх карточек. У пустого actions фильтра нет отдельной остановки фокуса.
2. Выберите карточку через Enter, другую через Space: статус показывает соответствующий курс.
3. Переключите категории: Frontend показывает два курса, Fullstack и Quality — по одному, «Все направления» — четыре.
4. Уменьшите окно до 320 px: длинный заголовок фильтра переносится, кнопки и содержимое остаются доступны.
