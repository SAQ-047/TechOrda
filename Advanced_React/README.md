# Продвинутый React · TechOrda

Задания используют npm workspaces: общие зависимости и версии находятся в корневом `package.json`, дерево зависимостей — в одном `package-lock.json`, установленные пакеты — в одном `node_modules`. У каждого задания свои исходники, команды Vite и сборка `dist`.

## Установка и запуск

Из папки `Advanced_React` установите зависимости один раз:

```bash
npm ci
```

| Задание | Запуск из Advanced_React | Адрес |
| --- | --- | --- |
| 01. Render и commit | `npm run dev:01` | http://127.0.0.1:5173/ |
| 02. Чистота render | `npm run dev:02` | http://127.0.0.1:5174/ |
| 03. Приоритет ввода | `npm run dev:03` | http://127.0.0.1:5175/ |
| 04. Отложенные результаты | `npm run dev:04` | http://127.0.0.1:5176/ |
| 05. Карточка через композицию | `npm run dev:05` | http://127.0.0.1:5177/ |

Для одновременного запуска используйте два терминала. Внутри папки задания также работает `npm run dev`, используя общие зависимости.

Сборка всех заданий: `npm run build`. Сборка одного: `npm run build --workspace=<имя-папки-задания>`. Просмотр production-сборок: `npm run preview:01` (порт 4173), `npm run preview:02` (порт 4174), `npm run preview:03` (порт 4175), `npm run preview:04` (порт 4176), `npm run preview:05` (порт 4177).

Новые задания размещайте в папках `06-…`, `07-…` и далее: шаблон workspaces `[0-9][0-9]-*` подключает их автоматически. В их `package.json` достаточно имени, `private`, `type` и команд запуска/сборки. Общие библиотеки добавляйте в корневой `package.json`; устанавливайте зависимости из `Advanced_React`. Кеш Vite каждого задания направляйте в `../node_modules/.vite/<имя-папки>`, чтобы внутри заданий не создавались дополнительные `node_modules`.
